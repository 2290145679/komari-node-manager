三、最近完成的核心功能与问题修复记录 (Completed Features & Bugfixes)
--------------------------------------------------------------------------------
1. 【核心】实时流量统计与秒级配额硬断流机制 (Real-time Traffic & Hard Cutoff):
   - 解决问题: 用户测速跑流后后台与用户中心始终显示 0B 流量，导致盗刷风险。
   - 核心机制:
     1) Sing-box 核心配置中动态为每位订阅用户分配 auth_user: ["sub_{id}"] 路由规则，
        出站映射至独立 direct 标签 out-sub-{id}，并启动 experimental.clash_api (127.0.0.1:9090)。
     2) 主控后台运行 TrafficCollector 线程 (每 2 秒一次)，精准比对长连接增量及全局瞬时闭合连接增量，
        将实时字节数累加回写至 SQLite 的 subscriptions.traffic_used_bytes 字段。
     3) 节点端 komari-node-sync.sh 内置轻量 Python 采集模块，定期向主控 POST /api/node-mgr/agent/report-traffic 上报分布式流量。
     4) 强配额熔断: 一旦 traffic_used_bytes >= traffic_limit_bytes，系统立即触发 Clash API
        DELETE /connections 斩断当前所有活跃长连接，并在下次节点配置同步中彻底剔除该用户 UUID。
   - 验证结果: 生产环境使用“朋友A”进行 500KB 真实代理请求压测，流量从 0B 准确增加至 500,444 字节 (488.71 KB)，
     用户中心与后台管理页面秒级同步。

2. 【修复】服务器删除时中转节点级联清理 (Cascade Delete for Relays):
   - 解决问题: 用户删除了 HKcloudx 服务器，但残留了中转落地节点导致脏数据。
   - 修复内容: 在 delete_server_fully() 中增加级联删除逻辑:
     server_uuid = ? OR (is_relay = 1 AND relay_server_uuid = ?)
     无论该机器是目标落地机还是中转中继机，关联节点一并彻底清理并重定向规则。

3. 【功能】用户中心改造成账号密码登录体系 (User Portal Username/Password Login):
   - 废除只认 token 登录的形式，支持 用户名/密码 登录与鉴权。
   - 用户登录后可在列表查看节点，节点服务器 IP 默认打码脱敏，支持点击眼睛切换显示。
   - 剥离用户管理的冗余复制订阅功能，收敛至用户中心与节点管理。

4. 【功能】部署指令一键切换免 sudo 选项 (Install Command Sudo Switcher):
   - 在后台生成一键部署脚本指令弹窗中，增加“带 sudo”与“去除 sudo”单选切换，
     解决部分精简环境或无 sudo 命令设备复制报错的问题。

5. 【UI】探针离线红色高亮特效 (Probe Offline Visual Highlight):
   - 探针总览页面中，对于心跳超时的离线服务器节点（如懒猫JPL），
     增加了明显的红框和红色高亮离线特效标识。

四、常用运维与管理命令备忘 (Ops Cheat Sheet)
--------------------------------------------------------------------------------
1. 查看与重启主控端 Node Manager:
   sudo systemctl status komari-node-mgr.service --no-pager
   sudo systemctl restart komari-node-mgr.service
   sudo journalctl -u komari-node-mgr.service -n 50 --no-pager

2. 查看与重启 Sing-box 服务:
   sudo systemctl status sing-box.service --no-pager
   sudo systemctl restart sing-box.service
   sudo journalctl -u sing-box.service -n 50 --no-pager

3. 查看本地 Sing-box Clash API 连接状态:
   curl -s http://127.0.0.1:9090/connections | jq .

4. 查询用户流量使用情况:
   sudo python3 -c '
   import sqlite3
   conn = sqlite3.connect("/opt/komari-pro/data/nodes.db")
   c = conn.cursor()
   c.execute("SELECT id, username, traffic_limit_bytes, traffic_used_bytes FROM subscriptions")
   for r in c.fetchall(): print(r)
   '

5. 重置指定用户流量为 0:
   sudo python3 -c '
   import sqlite3
   conn = sqlite3.connect("/opt/komari-pro/data/nodes.db")
   c = conn.cursor()
   c.execute("UPDATE subscriptions SET traffic_used_bytes = 0 WHERE id = 3")
   conn.commit()
   print("User 3 traffic reset to 0")
   '
